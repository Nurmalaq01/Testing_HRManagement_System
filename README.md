Manual test dengan website HR Management : [OrangHRM](https://opensource-demo.orangehrmlive.com/web/index.php/auth/login)
OrangeHRM adalah sebuah website untuk mengatur dan membantu pekerjaan HR terutama dalam management karyawan perusahaan.

Ada 3 fitur yang saya test :
- Fitur Attendance
  Fitur ini digunakan untuk mencatat/record dan absensi dari kehadiran karyawan di kantor
- Fitur Profile
  Berisi data-data pribadi dari karyawan
- Fitur Leave
  Fitur yang digunakan untuk karyawan mengajukan untuk tidak bekerja/absen dari kantor

  Tools yang digunakan untuk testing :
  - Microsoft Excel untuk membuat Test Case
  - Microsoft Word untuk membuat Bug Report
